Build simple 3D maps, fast.

Block out a level on a grid, texture it with a right-click, walk through it, then export a .glb that drops straight into Godot, Blender or any glTF viewer. A small, lightweight map builder written in plain C#.

Everything in the box

A whole level-blockout toolkit

No downloaded assets needed to start - every new map opens on a 1 m grid palette.

🧱

Grid building

Blocks, walls, ramps, stairs, roofs, arches and more - each with an exact triangle collider. Snap, stack, drag-paint and rectangle-fill.

🎨

Texture by right-click

Drop an image onto any object to make a material. World-space UVs keep texture density on every block size. Normal & roughness maps supported.

🎯

Move gizmo

Grab the X/Y/Z axis arrows and drag an object into place, snapping to the grid - the whole selection moves together.

🏠

37 prefabs

Houses, streets, blocks of flats, trees, lamp posts and benches that drop in assembled. Alt-click to edit any part; Ctrl+B to save your own.

🟢

Reachability overlay

Press F to flood-fill the walkable map from the spawn - green where you can walk, red where a platform is isolated. Multi-level maps that actually connect.

📦

GLB export

PBR materials with embedded textures, punctual lights, marker metadata and Godot -col/-rigid import suffixes.

🚶

Play mode

Press Tab and walk through your map on foot with the built-in third-person player.

💾

Autosave & JSON

Your map is a small, readable JSON file that saves itself - diffable, hand-editable, version-control friendly.
